# 公告发布细则（announcement-playbook）

> 由 SKILL.md Step 6 迁出的沿革、渲染细则与发布前检查。**分级策略的当前口径以 SKILL.md Step 6 为准**。

## 1. 分级策略沿革

| 日期 | 决策 | 内容 |
|---|---|---|
| 2026-09-02 | 确立 | 写库后询问用户是否发「数据更新公告」（MANUAL 来源） |
| 2026-09-03 | 模板固化 | 标题 `{M}月{D}日舞讯更新`；正文分组「新增门店 / 恢复营业」，店名 `[店名](venue://id)` 可点击 |

| 2026-09-10 | 全源一致 + 双向 | 门槛收紧为「全源一致」；**表⑤（关门/暂停）刻意不发公告**；新增「确认营业门店」版式处理零新增/零恢复的日子 |

## 2. 当前分发规则（速览）

| 情形 | 公告 |
|---|---|
| 表①（开门）/表③（新店）全源一致写库成功 | **直接 create+publish，无需询问** |
| 全源一致但平台已 OPEN（当日零写库） | **不发**（无正向内容，发了是噪音） |
| 表⑤（关门/暂停） | **不发**（纯噪音；暂停只写库 + 通知关注者） |
| 表② 放行 / 单源新店录入 / 混合批次 | **询问用户**后发 |
| 零新增零恢复但用户仍要发 | 用「确认营业门店」版式（见 §5） |

## 3. 发布前检查（固定动作）

1. `GET /admin/announcements?page=0&size=10` 扫一眼列表——看今天是否已有 DATA_UPDATE；
2. status 取值 `DRAFT / PUBLISHED / OFFLINE`；**OFFLINE 与昨日 PUBLISHED 均无碍**，直接 create+publish；
3. **仅当今日已发且信息不全（PUBLISHED）** → 先 `POST /admin/announcements/{旧id}/offline` 下线旧条，
   再 create + publish（09-06 实证：#18 与晚间 52 家新店合并为 #19，offline #18 → create #19 → publish）；
4. 接口链路：`POST /admin/announcements/create`（body `{title, content, category:"DATA_UPDATE", pinned?}`）
   → `POST /admin/announcements/{id}/publish`（缺省立即发布）。管理端 Web 后台「公告管理」同链路。

**询问话术**：汇报完成后附「**是否发一条公告？**（标题如『X月X日舞讯更新』）」；用户确认后执行
create+publish（本地 develop 也照做，用户确认即视为授权）。用户未确认 → 不创建公告。

## 4. 模板与渲染细则

标题：`{M}月{D}日舞讯更新`（category=DATA_UPDATE，pinned=true）

```
【新增门店 {N} 家】
- [门店名](venue://<venueId>)（城市·区县）
- …

【恢复营业 {M} 家】
- [门店名](venue://<venueId>)（城市·区县，可附状态/备注）
- …

以上门店点击可直接查看详情，营业状态以现场实际情况为准。
```

- **门店可点击链接 = `[店名](venue://<venueId>)`**（2026-09-03 前端已支持；能力见
  `docs/agents/34「正文链接」` + 小程序 `utils/announcementLinks.ts`）：归一化 `venue://12` → 详情页
  路径，towxml 渲染为 navigator 直达；外链/未知协议自动降级纯文本。
- 分组文案可选「新增门店 / 恢复营业 / 状态更新」；**仅一类门店时只列存在的分组标题**；
  今日停业等非 OPEN 的新增店也列出并在括号注明（如「苏州昆山，今日停业」）。
- **大批量（≥10 家跨多城）按城市分组渲染**（09-06 54 家实战 #19）：

  ```
  **城市名**（N 家）
  - [店名](venue://id)（城市·区县[，状态]）
  ```

  停业店统一注「，暂停营业」、OPEN 不注——比 50+ 行平铺更可读。城市小标题须用全称（滁州市），
  与门店括号内简称（滁州·来安县）并存不冲突。

## 5. 「确认营业门店」版式（2026-09-10 用户拍板，零新增/零恢复时）

当本轮零新增零恢复、但用户仍要发公告时，改为**列「全源一致确认营业中」的门店**：

- 标题不变（`{M}月{D}日舞讯更新`，DATA_UPDATE，pinned=true）；
- 正文首句：「今日已核对各来源舞讯，以下 **N 家门店**经两个来源共同确认今日营业中（按城市分组）：」
- 城市分组渲染（同 §4）；
- 结尾：「以上门店点击可直接查看详情。营业状态随时变动，以现场实际情况为准。」
- ⚠️ **口径必须写「两源共同确认」**，不能写成「全部营业门店」——与「未上榜即暂停」的关门口径
  会自相矛盾。

**09-10 首跑实证**：148 家 / 22 城，公告 #27（本地 develop）。
